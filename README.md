# Royal Estate Investment — Company Portfolio

A fully self-contained HTML presentation converted from PowerPoint.

## Usage

Open `index.html` in any modern browser.

### Navigation

| Action | Description |
|--------|-------------|
| `→` / `↓` / `Space` | Next slide |
| `←` / `↑` | Previous slide |
| `Home` | First slide |
| `End` | Last slide |
| Click left half | Previous slide |
| Click right half | Next slide |
| Swipe left/right | Next / Previous (mobile) |
| Dots at bottom | Jump to any slide |
| ⛶ icon (top-left) | Toggle fullscreen |

## File Structure

```
royal-estate-presentation/
├── index.html          # Main presentation file
├── slides/             # Slide images (slide-01.jpg … slide-15.jpg)
│   └── slide-XX.jpg
├── assets/             # Original media from the presentation
│   └── imageXX.png/jpeg
└── README.md
```

## Deploying to GitHub Pages

1. Push the entire folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Set source to `main` branch, `/ (root)`.
4. Your presentation will be live at `https://<username>.github.io/<repo>/`.
