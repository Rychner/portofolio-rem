## Sections

1. **Hero** — Full-screen intro with brand tagline and stats
2. **About** — Company overview, scope of work, commitment to quality
3. **Services** — Private Residences, Premium Villas, Government Projects
4. **Portfolio** — Featured projects: Golden Hour Villas, Michael Young Spa & Sauna, David Holme Residence
5. **Team** — Firza Aditya, Andika, Putu Reza Brahmastra Pradana, Aprizal Yuliansyah
6. **Contact** — Contact details + inquiry form

## Tech Stack

- Pure **HTML5 / CSS3 / Vanilla JS** — no frameworks required
- Google Fonts: Playfair Display + DM Sans
- Fully responsive (mobile-first)
- Scroll reveal animations, counter animations, smooth nav highlighting

## Deploying to GitHub Pages

1. Push this folder to a GitHub repository
2. Go to **Settings → Pages**
3. Set source to `main` branch, root `/`
4. Your site will be live at `https://<username>.github.io/<repo-name>/`
